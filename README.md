# Limatus

Limatus is a diagnose-and-steer quality loop for AI-generated content — prose and, soon, web pages — built to catch generic AI slop and enforce a specific publication or product's own style rules, not just generic patterns.

## Status

This package was newly extracted from Anth.us's Papyrus content system and is under active development. It is not yet on PyPI.
